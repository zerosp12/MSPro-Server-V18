// Item for Value
// One item the player hands in, and a value (Zen, WCoin, resets...) the player receives.
//   Item category: The category of the item.
//   Item index: The number of the item inside its category.
//   Item level: The level of the item. Any accepts or gives any level.
//   Luck: 1 the item has luck, 0 it has not. Any does not look at it.
//   Skill: 1 the item has skill, 0 it has not. Any does not look at it.
//   Durability: The durability of the item. Any does not look at it.
//   Additional option: The additional option, 0 to 7. Any does not look at it.
//   Excellent options: The excellent options: the sum of the options' values (up to 63). Any does not look at it.
//   Ancient option: 0 none, 1 and 2 are the two ancient sets.
//   Socket 1: The option of socket 1. Any does not look at it.
//   Socket 2: The option of socket 2. Any does not look at it.
//   Socket 3: The option of socket 3. Any does not look at it.
//   Socket 4: The option of socket 4. Any does not look at it.
//   Socket 5: The option of socket 5. Any does not look at it.
//   How many: How many of this item. 0 is taken as 1.
//   Value taken: What the player receives for the item: resets, master resets, coins, Zen and so on.
//   Amount taken: How much of that value the player receives.
//   Lasts (seconds): Only for rewards that expire.
