// AI State Transitions
// How a monster moves from one AI state to another. Each set is read by the AI units that point to it; for the state the monster is in, the rows are tried from the lowest priority up and the first one whose condition is true (and whose chance rolls) is used.
//   Transition: Number of the set of transitions, 0 to 299. An AI unit points to a set by this number. Rows with a higher number are ignored by the server.
//   Name: Only a note for you; the server does not use it.
//   Priority: 0 to 29. A lower number is checked first. If two rows of the same set and the same From state share a priority, the last one replaces the other; rows outside 0 to 29 are ignored.
//   From state: 0 Normal | 1 Move | 2 Attack | 3 Heal | 4 Avoid | 5 Help | 6 Special | 7 Event
//   To state: 0 Normal | 1 Move | 2 Attack | 3 Heal | 4 Avoid | 5 Help | 6 Special | 7 Event
//   When: Condition that must be true for the change. Types 4, 5, 7, 8, 11 and 12 use the Value column.
//   Chance (%): Chance, in percent, that the change happens once the condition is true. 100 always.
//   Value kind: The GameServer reads this column but never uses it. Leave it at *.
//   Value: Life points for "Life drops (value)", life percent for "Life drops (percent)", aggro level for "Aggro goes up/down", and the life percent below which an ally is healed for the heal conditions. Ignored by the other conditions.
//   Delay (ms): Milliseconds the monster waits after this change before another change is evaluated.
//-------------------------------------------------------------------------------------------------------------------------------------------------------------------------

//  Number     Name                        Priority    CurrentState    NextState    TransitionType    TransitionRate    TransitionValueType    TransitionValue    DelayTime
