//   Element: Number of the element, 0 to 99. AI units point to it by this number; higher numbers are ignored.
//   Name: Only a note for you; the server does not use it.
//   State it belongs to: 0 Normal | 1 Move | 2 Attack | 3 Heal | 4 Avoid | 5 Help | 6 Special | 7 Event
//   What it does: Kind of action. "Common", "Group move to the target" and "Event" do nothing in this GameServer.
//   Chance (%): Chance, in percent, that the action runs each time it is chosen. 100 always.
//   Delay (ms): The GameServer reads this column but never uses it (the pause comes from the AI unit and the state transitions).
//   Group or skill chance: What it means depends on the kind of action: for "Skill attack" it is the chance (%) of using the monster's skill kind 0; for "Change AI" it is the number of the AI group. The other kinds ignore it.
//   X, order or chance: Position X for "Move to the target", "Warp" (destination) and "Area attack" (centre, spread of 4 cells). For "Skill attack" it is the chance (%) of skill kind 1. For "Immune" it is the seconds of immunity to physical damage (default 10). For "Change AI" it is the order: 0 start AI, 1 AI 1, 2 AI 2, 3 AI 3 of the group members.
//   Y, chance or seconds: Position Y for "Move to the target", "Warp" (destination) and "Area attack" (centre). For "Skill attack" it is the chance (%) of skill kind 2. For "Immune" it is the seconds of immunity to magic damage (default 10). The other kinds ignore it.
