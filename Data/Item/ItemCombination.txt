//	[OptionType]
//--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
// Success Values
// What the combination gives when it works. Result type 0 uses the values of this row; types 1 and 2 copy the options of the first or the second item; type 3 merges the options of both.
//   Item: Category of the item given. With the item number at *, the result is the second item put in the window.
//   Chance of this item (%): Weight of this result among the ones of the combination; one of them is picked at random.
//   Result type: 0 Values of this row | 1 Copy from the first item | 2 Copy from the second item | 3 Merge both items
//   Lasts (seconds): Seconds the item given lasts. * or 0 does not expire.
//   Durability: Durability of the item given. * uses the default durability of the item.
//   Most excellent options: How many excellent options the item gets (the options are picked at random).
//   Ancient option: 0 none; 1 the first ancient type of the item, 2 the second (if the item lacks it, the other one is used).
//   Harmony option: Harmony option as stored in the item: 16 times the option (Index of JewelOfHarmonyOption.txt) plus its level (0 to 15). 0 none. Do not use * here.
//   380 option: 0 None | 128 380 option
//   Socket 1: 255 or * no socket, 254 an empty socket, otherwise the option number (the Index of Socket Options) plus 50 times its level from 0 to 4.
//   Socket 2: 255 or * no socket, 254 an empty socket, otherwise the option number (the Index of Socket Options) plus 50 times its level from 0 to 4.
//   Socket 3: 255 or * no socket, 254 an empty socket, otherwise the option number (the Index of Socket Options) plus 50 times its level from 0 to 4.
//   Socket 4: 255 or * no socket, 254 an empty socket, otherwise the option number (the Index of Socket Options) plus 50 times its level from 0 to 4.
//   Socket 5: 255 or * no socket, 254 an empty socket, otherwise the option number (the Index of Socket Options) plus 50 times its level from 0 to 4.
//   Socket bonus: 255 or * no bonus, otherwise the Index of Bonus Options.
//--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

//  Index      Type        ItemIndex    ItemRate    OptionType    Time        Durability    MinLevel    MaxLevel    Luck       Skill      MinOption    MaxOption    MaxExcellent    Ancient    Harmony    Option380    Socket1     Socket2     Socket3     Socket4     Socket5     SocketBonus
