// Items It Asks For
// Items the Chaos Machine must hold for a mix. Every row of a mix must be met, with exactly the amount it says, or the mix does not start.
//   Mix: Number of the mix inside this file.
//   Mix number: Mix number this requirement belongs to (the MixID of the first part).
//   Item: 0 Only the item below | 1 Any item of the range (takes one)
//   Item: Item category of the item (or of the first one of the range).
//   Item index: Item index in that category (or of the first one of the range).
//   Last item: Item category of the last item of the range. Only used when Range is 1; -1 otherwise.
//   Last item index: Item index of the last item of the range. Only used when Range is 1; -1 otherwise.
//   Level from: Lowest item level accepted. -1 accepts any.
//   Level to: Highest item level accepted. -1 accepts any.
//   Luck: 1 asks for an item with luck, 0 without. -1 does not check.
//   Skill: 1 asks for an item with its skill, 0 without. -1 does not check.
//   Additional option from: Lowest additional option level accepted (0 to 7). -1 accepts any.
//   Additional option to: Highest additional option level accepted (0 to 7). -1 accepts any.
//   Excellent options from: Fewest excellent options accepted. -1 accepts any.
//   Excellent options to: Most excellent options accepted. -1 accepts any.
//   Ancient: Any value other than -1 asks for an ancient item (the exact value is not compared). -1 does not check.
//   Socket: Any value other than -1 asks for an item with at least one socket (the number is not compared). -1 does not check.
//   Durability: Exact durability the item must have. -1 does not check. For stackable items (such as jewels) it is the amount in each stack, and the total asked is Count x this.
//   How many: How many items that fit must be in the machine; it must match exactly. For stackable items it is the number of stacks.
//-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
//  [0~65000]    [99~65000]    [Number]    [0~15]    [0~511]    [-1~15]    [-1~511]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]    [Number]      [0~9999]
//  Index        MixID         Range       Type      ID         Type2      ID2         LevelMin    LevelMax    Luck        Skill       OptMin      OptMax      ExcMin      ExcMax      Ancient     Socket      Durability    Count
//-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
