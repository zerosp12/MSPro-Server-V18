// Wheel Items
// The 12 slots of the wheel. A slot holds an item, a flag, or nothing (an empty slot); the chances are weights between the slots. Rows of an empty slot only have the first six values.
//   Slot: Number of the slot (1 to 12). Slots can be numbered in any order.
//   Chance: Weight of the slot in the draw. Each slot has a chance equal to its weight divided by the total of all the slots; they do not have to add up to 100.
//   X on the wheel: Position X of the slot picture on the wheel (client).
//   Y on the wheel: Position Y of the slot picture on the wheel (client).
//   Size: Size of the slot picture (1.0 is normal). Decimals are allowed.
//   Item category: Item category of the prize. * makes an empty slot (the player wins nothing). 100 makes the prize a flag: then the next value is the flag number (from Flag System) and the one after it the minutes it lasts.
//   Item index: Item index of the prize (or the flag number when the category is 100).
//   Item level: Level of the item (+0 to +15). For a flag this value is the minutes the flag lasts (0 never expires).
//   Durability: Durability of the item. * or 0 gives it the normal durability.
//   Skill: 1 gives the item its skill.
//   Luck: 1 gives the item luck.
//   Additional option: Additional option level (0 to 7).
//   Excellent options: Excellent options as a bit mask (0 to 63; 63 gives all six).
//   Ancient option: Ancient option. The server maps 1 and 21 to the first ancient type, 2 and 22 to the second, 3 and 4 to the next two (unverified what each type means); any other value gives none.
//   Harmony option: Harmony option byte as stored in the item (unverified).
//   380 option: 380 option byte of the item (unverified).
//   Socket 1: Only used when the item type has sockets, and only up to the number of sockets it has. 255 no socket, 254 empty slot, 200 to 246 option.
//   Socket 2: Only used when the item type has sockets, and only up to the number of sockets it has. 255 no socket, 254 empty slot, 200 to 246 option.
//   Socket 3: Only used when the item type has sockets, and only up to the number of sockets it has. 255 no socket, 254 empty slot, 200 to 246 option.
//   Socket 4: Only used when the item type has sockets, and only up to the number of sockets it has. 255 no socket, 254 empty slot, 200 to 246 option.
//   Socket 5: Only used when the item type has sockets, and only up to the number of sockets it has. 255 no socket, 254 empty slot, 200 to 246 option.
//   Lasts (seconds): Seconds the item lasts after it is won. 0 does not expire. (A flag instead lasts the minutes of the previous value.)
