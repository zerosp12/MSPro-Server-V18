//----------------------------------------------------------
// Command Description
// One row per command. When a player types the command, he receives the description.
//   Row ID: Number of the row (0 to 50). It must be different in every row.
//   Command: The chat command, with the slash, e.g. /rules (up to 31 characters). Letter case does not matter.
//   Description: Text the player receives (up to 127 characters). {0} is replaced by the name of the player; do not use other braces.
//----------------------------------------------------------
//  [0~50]    [Text]          [Text]
//  ID        Command         Description
//----------------------------------------------------------
    0         "/testeando"    "Comando test"
