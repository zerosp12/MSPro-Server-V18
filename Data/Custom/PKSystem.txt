// PK Levels
// One row per range of PK kills. A player gets the first row whose account level, and kill count range, fit. Rows should not overlap. A player who fits none gets no penalty.
//   Row: Number of the row. It must be different in every row.
//   Account level: 0 Free and above | 1 VIP 1 and above | 2 VIP 2 and above | 3 VIP 3 only
//   Fewest kills: Fewest PK kills of the player for this row. The kill count of a murderer goes up to 100.
//   Most kills: Most PK kills of the player for this row.
//   Minutes to reduce 1 kill: Minutes a player must stay alive without killing for the kill count to drop by 1.
//   Effect shown: Visual effect shown on the character while this row applies. * shows none.
//   Experience received (%): Percentage of the experience the player still receives. 100 means no penalty, 20 means only a fifth.
//   PvP damage reduced (%): Percentage taken off the damage the player does to other players.
//   PvP defense reduced (%): Percentage taken off the defense of the player when other players attack him.
//   PvM damage reduced (%): Percentage taken off the damage the player does to monsters.
//   PvM defense reduced (%): Percentage taken off the defense of the player when monsters attack him.
//   Items dropped: 0 Equipped items | 1 Everything in the inventory
//   How many items: How many items are dropped each time the chance succeeds (1 to 10).
//   Drop chance (%): Chance (%) that the player drops items when he dies.
//   Gate when logging in: Gate the player is moved to every time he logs in. * leaves him where he was.
