// Arenas
// One row per arena: its times, gates and who may enter. A row must exist for the arena to work.
//   Arena: Number of the arena (0 to 29). The prizes and the schedule use it.
//   Name: Name of the arena shown in the announcements (up to 31 characters).
//   Alarm before (minutes): Minutes before the scheduled time that the doors open and players can enter (1 to 59). Everyone is told at each minute.
//   Waiting time (minutes): Minutes of waiting inside after the doors close, before the fight starts.
//   Lasts (minutes): Minutes the fight lasts.
//   Closes after (minutes): Minutes after the fight before the arena can open again. The prizes are given when it starts.
//   Gate to enter: Gate players walk into to enter the arena (Gate.txt).
//   Gate at the end: Gate where players are taken when they are defeated or when it ends.
//   Fewest players: Fewest players for the fight to start; with fewer it is cancelled and the arena goes back to waiting. * counts as 1.
//   Most players: Most players that can enter (up to 100).
//   Deaths allowed: Deaths after which a player is taken out. * means never.
//   Lowest level: The lowest number of level that can enter. * has no limit.
//   Highest level: The highest number of level that can enter. * has no limit.
//   Lowest master level: The lowest number of master level that can enter. * has no limit.
//   Highest master level: The highest number of master level that can enter. * has no limit.
//   Fewest resets: The lowest number of resets that can enter. * has no limit.
//   Most resets: The highest number of resets that can enter. * has no limit.
//   Fewest master resets: The lowest number of master resets that can enter. * has no limit.
//   Most master resets: The highest number of master resets that can enter. * has no limit.
