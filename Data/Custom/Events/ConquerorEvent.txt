// Event
// The basic settings of the event.
//   Enabled: 1 turns the event on, 0 off.
//   Fewest players: Fewest registered players needed when the registration closes; with fewer, the event is cancelled.
//   Most players: Most players. The server does not use this value (unverified: it is read but never checked).
//   Map: Map where the registration NPC stands.
//   Registration NPC: Monster number of the NPC that registers players.
//   NPC X: Position X of the registration NPC on that map.
//   NPC Y: Position Y of the registration NPC on that map.
//   Only for guild members: Keep at 0. With 1 the server code refuses the players that are in a guild (it looks inverted; unverified in game).
//   Write a log (debug): 1 writes every step of the event to the log (only to look for problems).
//-------------------------------------------------------------------------------------------------------------
//  [Number]    [Number]      [Number]      [Number]    [Number]    [0~255]    [0~255]    [Number]     [Number]
//  Enable      MinPlayers    MaxPlayers    MapID       NpcIndex    NpcX       NpcY       OnlyGuild    Log

end

//   From X: Left side of the zone.
//   From Y: Top side of the zone.
//   To X: Right side of the zone (not less than the left side).
//   To Y: Bottom side of the zone (not less than the top side).
