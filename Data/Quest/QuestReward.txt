// What a player receives when a step of a quest is finished. Rewards here are points and class changes only: they never give items (the item columns are read and ignored). The GameServer reads 100 rows at most.
//   Quest Step: Not used by the GameServer; it only keeps the rows of a quest in order.
//   Reward: 0 None | 1 Stat Points | 2 2nd Class Evolution | 4 Hero Stat Points | 8 Combo Skill (Notify) | 16 3rd Class Evolution
//   Client Display Id: Number sent to the client with the reward so it shows the right message; it is not an item or a monster.
//   Amount: Stat Points: how many points. Combo Skill: sent to the client. The other kinds do not use it.
