// The quests: what starts each one, the quest and state it needs and the level and classes allowed. One row per class group, so a number can repeat; the first row whose state, required quest, level and class fit the player is the one used. The GameServer reads 500 rows at most.
//   Quest: The quest number, from 0 to 199 (the character keeps two bits for each of 200 quests). The client uses the same number.
//   Start type: 0 Offered By NPC | 1 Not Offered By NPC
//   NPC That Starts It: The NPC the player talks to (monster number). Only used when the start type is 0. None when no NPC offers it.
//   Applies While: 0 Not Started | 1 In Progress | 2 Completed | 3 Cancelled
//   Quest Required First: A quest the player must have in the state below first. None needs no other quest.
//   State Needed In That Quest: 0 Not Started | 1 In Progress | 2 Completed | 3 Cancelled
//   Minimum Level: Lowest character level that can take the quest. No limit does not check it.
//   Maximum Level: Highest character level that can take the quest. No limit does not check it.
